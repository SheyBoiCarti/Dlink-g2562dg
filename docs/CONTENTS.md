# Repository contents

| Location | Contents |
| --- | --- |
| `automation/` | Final Windows controller, tests, example configuration, and scheduler scripts |
| `scripts/` | Discovery/diagnostic scripts and canonical temporary SSH setup/rollback |
| `tests/` | Original offline discovery/diagnostic safety tests |
| `docs/` | Reproduction guide, research explanation, troubleshooting, detailed technical reports, and reading guide |
| `findings/` | Sanitized historical results and JSON command/result evidence |
| `phase 1/` | Original hardware, firmware, source, and uncertainty research |
| `research/controllers/` | Historical experiment source as text, plus original command batches |
| `research/firmware/` | Firmware provenance, node inventory, and portable filesystem manifest |
| `research/PUBLICATION_MANIFEST.json` | Inventory of imported historical records |

Start with the [reading guide](READING_GUIDE.md). [Publication notes](PUBLICATION.md) describe redactions and exclusions. The [firmware guide](../research/firmware/README.md) includes the recovered extractor and its validation. The original workspace and running deployment are not modified by preparing this export.
