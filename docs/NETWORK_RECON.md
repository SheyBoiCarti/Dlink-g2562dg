# Network reconnaissance

Observed 2026-10-19 at 16:57 UTC from the owner's Windows host. An on-link route `10.0.0.0/24` uses Ethernet. These measurements establish reachability from this host only, not every LAN segment, WAN exposure, boot defaults, or persistent service settings.

| TCP port | Observed state | Identified service | Evidence |
|---|---|---|---|
| 21 | Open | FTP, vsFTPd 3.0.2 (self-reported) | Connection and FTP 220 greeting; recognized product extracted from greeting |
| 22 | Open | SSH 2.0, Dropbear 2014.63 (self-reported) | SSH identification; no client SSH handshake or authentication performed |
| 23 | Open | Telnet negotiation | 12 received bytes containing IAC negotiation; no response or login sent |
| 53 | Open | Unknown; conventional DNS/TCP port | TCP connect only; no DNS query or UDP test |
| 80 | Open | HTTP | Root GET returns 302; browser reaches D-Link login page |
| 443 | Open | TLS/HTTPS candidate | TCP succeeds; default Python TLS handshake fails with `SSLV3_ALERT_HANDSHAKE_FAILURE` |
| 8080 | Timeout | Unknown | No TCP completion within 2 seconds; HTTP check also times out |
| 8443 | Timeout | Unknown | No TCP completion within 2 seconds; HTTPS check also times out |

Authentication: HTTP presents a username/password form. FTP/SSH/Telnet authentication requirements, allowed accounts and resulting privileges remain untested. No root or ordinary shell access established. Port 443's error does not prove SSLv3 is supported: the OpenSSL error name is not a negotiated protocol version. No ciphers or certificates were enumerated and no insecure fallback used.

Root HTTP response: status 302, Location present (value omitted), no Server, Content-Type, WWW-Authenticate or Set-Cookie header observed. Browser followed the redirect within the same router to `/page/login/login.html`. This endpoint returns the visible login interface; no authentication bypass tried.
