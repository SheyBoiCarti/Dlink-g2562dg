# Supported findings

1. The owner's web UI reports model `DSL-G2562DG` and software `TK_1.00TK_V1.2.12ak_20221018` (user-provided firsthand observation).
2. D-Link Southern Africa maintains a product page for DSL-G2562DG/TK. [Source](https://www.d-link.co.za/product/dsl-g2562dg-tk/)
3. Public FTP index mirrors list three Telkom `aj` images and one OpenMarket `al` image, with the filenames recorded in `docs/FIRMWARE.md`. [Sources](https://www.mmnt.net/db/0/0/ftp.d-link.co.za/DSL/DSL-G2562DG%20%28Telkom%29/firmware/), [OpenMarket](https://www.mmnt.net/db/0/0/ftp.d-link.co.za/DSL/DSL-G2562DG%20%28Telkom%29/firmware/Firmware%20for%20FTP)
4. At least one public Reddit discussion contains reports of shell access and VSPM3XX/OpenWrt-labeled firmware. This confirms that such *reports exist*, not that the method is reproducible. [Source](https://www.reddit.com/r/openwrt/comments/1fnicwy/openwrt_on_dlink_dslg2562dg/)
5. A community technical forum associates a DSL-G2562DG T1 with TriDuctor VSPM340. This is an attribution, not direct board verification. [Source](https://www.hwupgrade.it/forum/archive/index.php/t-2653735.html)
